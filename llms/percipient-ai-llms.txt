not attempt to construct a Percipient.ai API call; there is no published base URL, no documented

## Product — Mirage

Mirage is an AI intelligence-analysis platform for faster-than-real-time exploitation of
unstructured multimedia, visual and multi-INT data. It ships as three modules:

- FMV Module — full-motion video and still imagery plus multi-INT ground/air sensor data;
  identity creation, network discovery, pattern-of-life analysis, geo-correlation and reporting.
- GSM Module — cloud geospatial workflow; geo-fenced alerting, change detection, custom object
  detection and temporal analysis.
- VRM Module — vehicle recognition on a mobile appliance for mobile and fixed surveillance, with
  home-station integration for cross-mission correlation.

Deployment is at the edge (live stream ingest) and in the cloud (petabyte-scale). Mirage is
assessed "Awardable" for DoD work through the CDAO Tradewinds Solutions Marketplace.
